# CoopHub SA

A platform that helps university students discover and manage internship opportunities.

## 📌 About the Project

CoopHub SA is a web-based platform designed to help university students find internship opportunities and manage their applications in one place.

## 🎯 Project Goals

- Help students discover internship opportunities.
- Make it easier to search and filter opportunities.
- Allow students to save internship opportunities.
- Track internship applications and their status.
- Provide a simple and organized dashboard.

## 🛠️ Technologies

The technologies used in this project will include:

- HTML
- CSS
- JavaScript
- React
- Node.js
- Express
- PostgreSQL
- Git & GitHub
